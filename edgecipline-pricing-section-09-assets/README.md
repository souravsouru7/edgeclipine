# Edgecipline section 09 asset kit

The reference is included for comparison, not deployment. The 2160×3840 clean background is the only photographic production image. Logo, feature/check icons, topographic texture, Pro highlight, CTA highlight, button visual, and progress rail are separate SVGs. The pricing matrix, wording and clickable CTA should be live HTML/CSS, as directed by `PROMPT_FOR_CODEX.md`.

The generated background was exported at 4K portrait dimensions from a smaller image; it is not native 4K detail. Decorative SVG glows are resizable and independently animatable. The screenshot's tier availability and “Same tools” copy disagree; verify actual entitlements before publishing.

Files are grouped in `background/`, `icons/`, `effects/`, `ui/`, and `reference/`. The `demo/` directory contains an animation stylesheet and a short integration guide.
