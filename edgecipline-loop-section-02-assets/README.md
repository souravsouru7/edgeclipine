|---|---|

| Four individual cutouts | `stages/01-…png` to `04-…png`, each transparent and 3840px wide |
| Animated loop | `path/emerald-loop-route.svg` |

| Implementation guide | `PROMPT_FOR_CODEX.md` |

Headline, paragraph and stage labels must be live HTML. SVG paths are scalable independent layers; the four stages can appear independently on scroll. The 4K raster dimensions are upscales of generated source art, and cannot introduce details missing in the source. Some silhouettes and rocks were reconstructed, so visual pixel identity with the flattened reference is not possible.
